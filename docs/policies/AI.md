# AI Assistance Policy (Fork)

This fork permits AI-assisted development, code review, research, documentation, debugging, and testing.

## Contribution standards

- Contributors remain responsible for understanding, reviewing, and validating the changes they submit.
- Changes must meet the project's normal code-quality, testing, security, and licensing standards.
- Do not submit secrets, credentials, private user data, or unpublished security reports to external AI services.
- Do not spam issues or pull requests with unreviewed generated material.
- Human authorship must not be falsely claimed for work not performed by a human.

## Attribution

AI-tool usage does not require attribution, disclosure statements, trailers, co-author lines, or other autogenerated provenance in this fork. Contributors may disclose tool usage voluntarily.

This policy applies only to this fork. Any contributions proposed to another repository must follow that destination repository's current contribution rules.
