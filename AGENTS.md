# AGENTS

Read and follow the AI policy found in `docs/policies/AI.md`, and the coding policies found in `docs/policies/Coding.md`.

## Agent repository permissions

With a user-authorized, scoped engineering assignment, agents may create feature branches, commit and push changes to those branches, and open or update draft pull requests for review.

Do not push directly to `main` or another protected branch, merge pull requests, tag, publish releases or APKs, deploy, install software on devices, flash hardware, rewrite history, or perform destructive operations without the user's explicit authorization for that operation.

Do not manually dispatch hosted CI workflows without explicit authorization. Treat unresolved CI warnings and failures as blockers rather than claiming clean acceptance.

Keep changes within the user's authorized scope. Preserve existing user work and upstream copyright and license notices. Do not add unsolicited AI attribution or falsely claim human authorship or testing.

Keep comments to a reasonable level. Do not overexplain or add/remove comments from unrelated parts of the codebase.
